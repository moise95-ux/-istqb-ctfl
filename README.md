# ISTQB CTFL v4.0.1 — Application de révision V8

Cette version est conçue pour une préparation plus complète à l'examen CTFL.

## Nouveautés V8
- Cours détaillés directement intégrés dans l'application : pas besoin d'ouvrir le PDF pour apprendre.
- Contenu pédagogique aligné sur le syllabus officiel CTFL v4.0.1 (15/09/2024), paraphrasé pour l'apprentissage.
- QCM par chapitre.
- Examen blanc pour chacun des 6 chapitres : 15 questions, chronomètre 60 min, objectif conseillé 70 %.
- 5 examens blancs complets : 40 questions, chronomètre 60 min, répartition 8/6/4/11/9/2 et seuil 26/40.
- Corrections détaillées avec explication et objectif d'apprentissage.
- Statistiques locales.
- PWA compatible iPhone/Safari et GitHub Pages.

## Important
Le contenu de cours de cette application est une reformulation pédagogique du CTFL v4.0.1. Il ne reproduit pas intégralement le syllabus officiel ni les examens officiels. Les questions de l'application sont originales.

Référence officielle : ISTQB CTFL Syllabus v4.0.1, 15 septembre 2024.
