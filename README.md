# ISTQB CTFL v4.0.1 — Application de révision (V7)

Application de préparation CTFL compatible GitHub Pages, iPhone Safari et PWA.

## Contenu
- 6 chapitres de cours en français
- QCM par chapitre
- 5 examens blancs d'entraînement de 40 questions
- Chronomètre de 60 minutes
- Seuil de réussite : 26/40
- Correction détaillée et objectifs pédagogiques
- Statistiques locales
- Syllabus français CTFL v4.0 fourni dans le ZIP
- Accès direct au **syllabus officiel CTFL v4.0.1**
- Accès direct aux **examens blancs officiels A, B, C et D** et à leurs corrigés

## Important
Le syllabus officiel v4.0.1 et les examens blancs officiels sont des documents ISTQB. Pour cette V7, les liens officiels sont intégrés dans `ressources.html` afin d'ouvrir les PDF depuis ISTQB. Le PDF français inclus est la version CTFL v4.0 du 12 avril 2023, antérieure à la v4.0.1.

Les questions d'entraînement de l'application sont originales : elles s'inspirent des objectifs d'apprentissage, de la répartition et du niveau des ressources officielles, sans reproduire mot pour mot les questions officielles.

Source officielle : https://www.istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/
