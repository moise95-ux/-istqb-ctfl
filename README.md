# ISTQB CTFL v4.0.1 — Application de révision

Application autonome compatible GitHub Pages et iPhone.

## Contenu
- 6 chapitres de cours en français
- QCM par chapitre
- 5 examens blancs de 40 questions
- Chronomètre 60 minutes
- Seuil de réussite 26/40
- Navigation avant/arrière et accès direct aux questions
- Correction détaillée
- Statistiques locales
- PWA / fonctionnement hors ligne après chargement

Les questions sont originales et alignées sur les notions et objectifs du CTFL v4.0.1 ; elles ne reproduisent pas mot pour mot les examens officiels.
